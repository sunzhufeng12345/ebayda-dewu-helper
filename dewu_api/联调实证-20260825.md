## 1. 签名算法（官方 doc 1016729196 实录，实测通过）

- 签名基底 = 全部请求参数（app_key + timestamp + 业务参数），移除 null 与 secret
- 值序列化：bool→`"true"/"false"`、数字→str、list→元素（str 原样/对象紧凑 JSON）逗号拼接、dict→紧凑 JSON（key 排序、递归去 null）
- key 字典序排序，Java URLEncoder 风格编码（空格→`+`、`*`不编码、`~`→`%7E`、`%XX` 大写）
- 拼 `k1=v1&k2=v2...` 末尾直接拼 APP_SECRET（不编码），UTF-8 MD5 **转大写**
- **请求形态：全部参数（含 app_key/timestamp/sign）放 JSON body**，实测网关按 body 验签通过（"放 query"的猜测作废）

实现：`dewu_api/dewu_api_client.py` 的 `create_sign()`（含官方规则自检）。

## 4. upload_media 真实形态（与直觉不同）

`POST /dop/api/v1/nps/upload_media` **不是 multipart**：

```json
{"app_key": "...", "timestamp": 1787..., "sign": "...", "file_bytes": "<图片base64>", "type": 1}
```

- 返回 `data` 直接是 img_key **字符串**（不是对象）
- 缺字段报 `410 必填字段[file_bytes]/[type]为空`（可用来探测必填项）
- `type` 取值沙箱不校验（1 即可）

### 7.1 ISV 授权（OAuth）

- 入驻身份是「软件服务商」（非自研商家），调生产必须带 `access_token`
- 授权 URL：`https://open.dewu.com/authorize?app_key=...&redirect_uri=...&state=...`（回调配的是占位 `www.example.com`，code 在跳转后 URL 里手工截取）
- 换 token：`POST https://open.dewu.com/api/v1/h5/passport/v1/oauth2/token`（client_id/client_secret/authorization_code，无需签名）
- token 存 `dewu_api/tokens.json`（已 gitignore）；access_token 24h、refresh_token 180d，客户端已实现自动注入+`refresh_access_token()`
- **必须商家主账号授权**（子账号报"请使用入驻商家后台的主账号登录授权"）
- access_token 放进**签名基底**（与业务参数一起排序签名、放 JSON body）

### 7.2 create 关键入参实证（踩坑记录）

| 字段 | 实证 |
|---|---|
| `base_properties[].property_id/definition_id` | **可填 0 占位**过必填校验（真实属性模板 id 未开放查询接口；草稿可在商家后台补充） |
| `base_properties[]` 结构 | 需 `property_type:1, value_type:0, property_name, value, end_value, level:1, image_url:""`（缺一报 407 逐字段必填） |
| `size_table[].size_value` | ~~必须 JSON 字符串~~ **已推翻（2026-08-27）**：JSON 字符串 API 虽接受但后台渲染成碎片。正确格式见下 |

**size_table 正确格式（2026-08-27 抓 stark `draftDetail` 旧草稿实证）**：列式——首行 `{size_key:"尺码", size_value:"M,L,XL", remark_sort:0, type:1}`（尺码名逗号分隔），其后每个测量参数一行 `{size_key:"衣长", size_value:"64,66,68", type:2}`（值按尺码顺序逗号分隔）。得物前端按 `size_value.split(",")` 渲染。参数名用裸名（衣长/胸围/袖长，不带 (cm)）。证据：`/tmp/prop_packets/qp_01_draftDetail.json`。
| `sku_list[].property_list` | 无需 property_type（官方示例即无） |
| 真实 id 来源 | `product_pool/list` 反查：店铺在售 1107 条 → 永言 brand_id=1048353、卫衣 category_id=1002848 |
