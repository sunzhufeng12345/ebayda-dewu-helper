# 尺码表图片 OCR JSON 脚本设计

日期：2026-08-04
状态：已获用户确认，进入实现

## 目标

新增一个独立 Python 脚本。脚本读取文件顶部硬编码的本地图片路径，调用 OpenAI 视觉模型，只提取图片中的尺码表文字，并打印固定结构的 JSON。

## 输出结构

```json
{
  "tables": [
    {
      "headers": ["尺码", "衣长", "胸围"],
      "rows": [["M", "70", "118"]]
    }
  ],
  "texts": ["温馨提示：误差范围为1-3CM"]
}
```

- 所有 OCR 内容都保留为字符串，不做单位转换、字段推断或品类判断。
- `tables` 支持图片中出现多张表；每张表由表头和二维行数据组成。
- 表格外的说明文字放入 `texts`。
- 看不清的单元格使用空字符串，不猜测内容。

## 实现与错误处理

- 使用 `openai` Python SDK 的图片消息格式和 JSON mode。
- 图片由本地文件转为 base64 data URL。
- API Key 和图片路径都在源码顶部常量中修改；Key 使用明显占位符，避免误把占位值当成可用凭据。
- 解析模型响应后用 `json.loads` 校验 JSON；文件不存在、缺少 API Key、响应不是合法 JSON 时直接抛出清晰错误。

## 验证

- 单元测试覆盖响应 JSON 的固定顶层结构和字符串二维表数据。
- 通过 Python 编译检查；不在本地验证中发起真实 API 请求。
